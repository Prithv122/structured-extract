### Global Configuration Options

|                     Name                      |                                                                                                  Description                                                                                                  |    Type     |                    Default value                    |
|----|--------|--|---|
| `enable_external_file_cache`                  | Allow the database to cache external files (e.g., Parquet) in memory.                                                                                                                                         | `BOOLEAN`   | `true`                                              |
